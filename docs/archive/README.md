# docs/archive

Spec storiche del progetto, conservate per la cronologia delle decisioni — **non** come riferimento sullo stato attuale.

I dettagli tecnici qui dentro sono in buona parte superati (formati lezione, struttura cartelle, stack, numeri). Per come stanno le cose adesso vedi [`/CLAUDE.md`](../../CLAUDE.md).

| File | Cosa contiene di ancora utile |
|---|---|
| `PROMPTLY.md` | Brief originale del prodotto: vision, business model freemium, razionale del design system (palette, "tool view"), taxonomy degli eventi PostHog. |
| `LANDING.md` | Brief della landing (aprile 2026) + head note che descrive il redesign editoriale di maggio 2026. Restano validi target, tono, pricing nascosto, bilinguismo, performance target. |
| `DASHBOARD_V2.md` | Design spec della mappa visiva: zone bioma, sistema livelli/robot, catalogo e condizioni di sblocco delle bonus path, sistema referral. Implementato in `components/promptly/map/`. |
