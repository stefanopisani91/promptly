# Promptly — App UI Kit

Recreations of the authenticated lesson app: dashboard, path overview, and lesson player.

**Components**

- `AppShell.jsx` — sidebar + top bar with streak/XP
- `Sidebar.jsx` — nav + user card
- `TopBar.jsx` — streak fire pill, XP toast, freeze count, avatar
- `Dashboard.jsx` — daily-goal ring, continue-where-you-left-off card, path map
- `PathOverview.jsx` — list of lessons in a path with locks + checkmarks
- `LessonPlayer.jsx` — fill-in-the-blank exercise screen with progress bar
